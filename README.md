# Elsewhere

A responsive travel inspiration website built with HTML, CSS, and JavaScript. Includes destination filters, accessible destination dialogs, and a trip inspiration form. Suggestions are editorial examples, not reservations or live travel availability.

## Run locally

From this directory:

```sh
python3 -m http.server 8000
```

Open the site on port 8000 in a browser. No dependencies or build step are required. Photos use Unsplash and fonts use Google Fonts; an internet connection is needed for those assets. System fonts work as a fallback.

## Files

- `index.html`: content and layout
- `style.css`: responsive styles
- `app.js`: destination data and interactions

Deploy the directory to any static web host.
